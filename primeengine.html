PrimeEngine

PrimeEngine is a custom C++ engine with Lua scripting. Building on a base engine by Artem Kovalovs, I extended the rendering pipeline, animation system, physics integration, event architecture, and developer tooling.

Gallery

Frustum Culling
Implemented view frustum culling to prevent off-camera objects from entering the render pipeline. This demo visualizes culling; in stress scenes frustum filtering improved performance from ~30 → 60 FPS.
Animation Blending
Implemented animation blending and weighted state transitions. Demonstrates blending between locomotion states and layered animation channels.
Physics & Collision
Implemented gravity, collision detection, and surface sliding. Collision resolution uses surface normals to enable smooth gliding along geometry.
Occlusion Culling
Implemented an occlusion pass to reduce hidden surface rendering; occlusion produced limited gains in this scene, indicating further optimization is needed.
Targeting & Orientation
Implemented object targeting and orientation references for dynamic rotation toward other entities.
Waypoint Navigation
Implemented waypoint-based navigation allowing entities to travel to specified destinations, either randomly or intentionally.
Lua Event System
Added onto a Lua-driven event system enabling scripted interactions; example shows chained events triggering actions and retreats based on distance.
